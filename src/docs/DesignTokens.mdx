# Design Tokens

Nguồn: `src/theme/tokens.ts` (MUI + antd) và `src/styles/global.css` (Tailwind: `@theme` cho light, `[data-theme='dark']` cho dark).
Khi đổi giá trị, cập nhật **cả hai** file.

## Màu thương hiệu / trạng thái

Giống nhau ở cả 2 mode. Tailwind: `bg-primary`, `text-error`, `border-success`...

<ColorPalette>
  <ColorItem
    title="primary"
    subtitle="--color-primary"
    colors={{ primary: tokens.color.primary }}
  />
  <ColorItem
    title="secondary"
    subtitle="--color-secondary"
    colors={{ secondary: tokens.color.secondary }}
  />
  <ColorItem
    title="status"
    subtitle="success / warning / error / info"
    colors={{
      success: tokens.color.success,
      warning: tokens.color.warning,
      error: tokens.color.error,
      info: tokens.color.info,
    }}
  />
</ColorPalette>

## Màu nền / chữ / viền — đổi theo theme

Tailwind: `text-text`, `text-text-secondary`, `bg-background`, `bg-surface`, `border-border`. Class tự đổi màu khi chuyển dark mode, không cần `dark:`.

<ColorPalette>
  <ColorItem
    title="Light"
    subtitle="text / text-secondary / background / surface / border"
    colors={tokens.mode.light}
  />
  <ColorItem
    title="Dark"
    subtitle="text / text-secondary / background / surface / border"
    colors={tokens.mode.dark}
  />
</ColorPalette>

## Typography

Font: `{tokens.font.family}` — size cơ sở `{tokens.font.size}px`. Dùng atom `Heading` / `Text` thay vì tự viết class.

<Typeset
  fontFamily={tokens.font.family}
  fontSizes={[12, 14, 16, 20, 24, 30]}
  sampleText="Chữ mẫu tiếng Việt"
/>

## Bo góc

`borderRadius = {tokens.radius}px` — Tailwind: `rounded-app`.
